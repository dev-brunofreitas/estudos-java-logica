# ☕ Estudos de Java e Lógica de Programação

Este repositório reúne exercícios, conceitos e pequenos projetos desenvolvidos durante a minha jornada de estudos em **Java** e **Programação Orientada a Objetos (POO)**.

---

## 🚀 Conteúdos Abordados

O projeto está organizado em pacotes estruturados por conceito:

- **Sintaxe & Lógica Basica:** `LogicaSequencial`, `LogicaCondicional`, `EstruturaRepeticao` e `Array`.
- **Coleções em Java:** Exercícios práticos com `ArrayList`, `HashMap` e `TreeMap`.
- **Orientação a Objetos (POO):**
  - **Abstração & Interfaces:** Classes abstratas, métodos e interfaces (`Pessoa`, `Funcionario`).
  - **Encapsulamento & Herança:** Relações entre classes (`Animal`, `Cachorro`, `Galinha`).
  - **Polimorfismo:** Sobrescrita de métodos e reutilização de código.
  - **Associação de Objetos:** Relações do tipo *tem-um* (`Motor`, `Casa`, `Construcao`).
- **Tratamento de Exceções:** Manipulação de exceções personalizadas (`ConflictException`), verificadas e não verificadas, além de leitura de ficheiros (`LeitorDocumentos`).

---

## 🛠️ Tecnologias e Ferramentas

- **Linguagem:** Java (JDK 17+)
